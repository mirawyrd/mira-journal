# Mira Journal — technical pilot

A neutral publishing test at https://mirawyrd.github.io/mira-journal/.

## Files

- `pilot-entry.md` is the canonical sample entry: Markdown text, dates, status and source note.
- `about.md` describes this technical pilot.
- `index.html`, `_layouts/default.html`, `style.css` and `_config.yml` render the site through GitHub Pages / Jekyll.

## Editing and recovery

Edit the Markdown source and add a dated `revision_note` for a material correction. Commit the change with a descriptive message. GitHub Pages publishes from `main`, repository root.

The source and revision-history links are shown below each Markdown page. Download the repository ZIP to recover the current source files; clone the repository to retain its commit history as well.
